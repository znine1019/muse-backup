## 5. 云数据库设计摘要

阶段1计划创建以下集合：

| 集合 | 用途 |
|---|---|
| `users` | 微信用户映射、账号状态、已授权角色 |
| `student_profiles` | 学生注册基础资料与审核状态 |
| `role_bindings` | 角色授权和撤销记录 |
| `registration_reviews` | 每次注册提交及审核结果 |
| `training_groups` | 训练组基础信息 |
| `group_memberships` | 学生、教练员与训练组归属 |
| `audit_logs` | 身份、权限、审核和范围变更审计 |
| `system_config` | 首位开发者初始化状态等系统配置 |

字段、权限和索引的完整清单见《阶段1云端部署与测试清单》。
