# 阶段1｜云端部署前安全检查报告

**检查日期：2026-10-12**  
**检查范围：** 管理员初始化、8 个云数据库集合、`api` 云函数、`health_check` 云函数和关键安全单元测试。  
**执行限制：** 本次只修改本地代码；未创建集合、未部署云函数、未执行初始化、未修改任何云端数据。

## 1. 管理员初始化安全

### 检查前问题

1. 原实现只验证可信 OpenID 和一次性码，没有额外的“预先授权管理员 OpenID”条件。
2. 原实现先查询再更新，两个并发请求存在同时通过检查后再写入的可能。
3. 初始化状态虽然会写为 `true`，但并发写入缺少数据库事务保护。

### 修复结果

- 新增 `BOOTSTRAP_ADMIN_OPENIDS` 服务端环境变量，只允许白名单中的可信 OpenID 进入初始化。
- 保留 `BOOTSTRAP_ADMIN_CODE`，初始化码不进入前端、Git 或普通日志。
- 初始化必须同时满足：
  - 调用身份来自 `cloud.getWXContext().OPENID`；
  - OpenID 位于 `BOOTSTRAP_ADMIN_OPENIDS` 白名单；
  - 一次性初始化码正确；
  - `system_config/bootstrap.developerInitialized` 为 `false`。
- 使用 `db.runTransaction` 在同一个事务中更新：
  `wx-server-sdk@4.0.2` 类型定义确认提供 `Database.runTransaction`、事务集合引用及文档 `get/set/update` 方法。
  - 开发者角色；
  - 角色绑定；
  - `system_config/bootstrap` 初始化状态；
  - 审计记录。
- 同一个 `bootstrap` 配置文档作为并发控制点。两个并发请求最多只有一个事务成功；后到请求看到 `developerInitialized = true` 后返回 `BOOTSTRAP_COMPLETED`。
- 初始化完成后必须删除两个初始化环境变量，同时配置状态永久保留为 `true`，即使误保留初始化码也不能再次初始化。
- 普通 `auth.login` 只创建 `pending_profile` 账号，不会调用初始化逻辑，也不会自动获得任何角色。

## 2. 数据库权限设计

以下 8 个集合必须设置为“仅管理员可读写”：

`users`、`student_profiles`、`role_bindings`、`registration_reviews`、`training_groups`、`group_memberships`、`audit_logs`、`system_config`。

代码检查结论：

- 前端没有 `wx.cloud.database()` 直接访问。
- 前端只通过 `wx.cloud.callFunction` 调用 `api`。
- 学生档案接口不接收目标 `studentId`，只读取当前可信身份对应档案。
- 教练注册审核在服务端查询 `group_memberships`，只允许审核负责训练组内学生。
- 开发者接口每次重新检查服务端角色。
- 数据库权限规则尚未在云端设置，当前只能确认代码和部署说明，不能确认云端实际规则已经生效。

## 3. 云函数安全检查

### `api`

- 所有 action 均从 `cloud.getWXContext()` 获取可信 OpenID。
- 不从前端接收 `openid`、`role`、`isAdmin` 作为授权依据。
- 前端可以提交目标用户 ID 和角色名称，但所有操作都会在服务端检查当前调用者是否为有效开发者。
- 账号停用后，`loadUser` 会拒绝后续内部数据操作。
- 重复登录使用基于 AppID 和 OpenID 的确定性用户 ID。
- 重复注册提交在 `pending_review` 状态返回幂等结果，不新增审核记录。
- 注册审核和开发者初始化使用数据库事务，避免重复成功。
- 错误响应只返回公开错误码和中文提示，不返回数据库字段或环境配置。
- 日志只记录公开错误码，不记录初始化码、OpenID、身份证或学生资料。

### `health_check`

- 已增加可信微信身份检查，无 OpenID 调用返回 `UNAUTHENTICATED`。
- 仅返回云函数就绪状态、数据库是否可访问和服务器时间。
- 不返回环境 ID、密钥、集合字段或业务数据。
- 不执行写操作。

## 4. 安全单元测试

已执行：

```powershell
node --test tests\phase1\*.test.js
node scripts\validate-phase1.js
```

覆盖结果：

- 初始化同时校验预授权 OpenID 和一次性码。
- 普通用户即使提交正确初始化码也不能初始化。
- 已完成初始化后永久拒绝再次初始化。
- 并发初始化顺序执行时仅允许一个成功。
- 重复待审核注册返回幂等结果，不重复创建审核。
- 角色选择只使用服务端已知角色。
- 教练只能审核负责训练组内学生。
- 学生不能获得开发者权限。
- 审查和角色参数拒绝任意值。
- 静态检查确认云函数使用动态环境、可信身份、事务保护和环境变量初始化凭据。
- 前端敏感信息扫描通过。

当前结果：15 项安全单元测试通过，317 项结构检查通过。
