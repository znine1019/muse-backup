# 乔格训迹系统｜V1.6.5 新粗野遥测 × 横向分页 Deck 设计规范（R8）

## 1. 背景与范式切换决策

R5 / R6 两轮采用 `dark-mode-oled + data-dense-dashboard + editorial-grid` 的结果已经验证：**纵向分区带（Vertical Band Stack）无论如何换色，在手机屏幕上的首屏结构与操作心智都会高度同质**。

本轮（R8）依据已安装的 `ui-ux-pro-max` skill 执行实测检索，彻底更换视觉范式与布局模型，全面切换为 **Neo-Brutalist Telemetry × Horizontal Paged Deck（新粗野电子遥测 × 横向分页卡片甲板）**。

### 1.1 `ui-ux-pro-max` 真实检索摘要

执行脚本：`C:\Users\Administrator\.gemini\config\skills\ui-ux-pro-max\scripts\search.py`（全部退出码 `0`）：

1. `--domain style "brutalism raw bold border high contrast"`：命中 **Brutalism / Neo-Brutalism**——主张 `0px` 绝对直角、高可见度 `2px` (`4rpx`) 实线边框、裸露网格分割线、硬偏移零模糊投影（`6rpx 6rpx 0 #00A6FF`）、超高字重标题（700–900）与非对称索引编号，彻底去除柔光卡片与圆角装饰。
2. `--domain typography "brutalist monospace bold tabular numbers"`：命中 **Brutalist Raw / Kinetic Brutalism**——主数据全面采用等宽数字（`DIN Alternate / SF Mono / Consolas` + `tabular-nums` + `font-feature-settings: 'tnum'`），英雄数值放大至 `88rpx` 900 字重。
3. `--domain ux "horizontal swipe tabs drawer table mobile"`：主张高频多维工作台采用**横向 `<swiper>` 分页 + 顶部可点击索引轨**替代冗长纵向滚动，长列表改为**双栏表格 + 底部抽屉详情**，筛选器收入底部抽屉，长表单拆为横向分步。
4. `--domain chart "sports telemetry line chart dark high contrast"`：统计与报告页首屏直出高对比电光科技蓝趋势图（`.jg-chart-stage`），避免被筛选器挤出首屏。

## 2. 严格视觉基底（Neo-Brutalist Telemetry）

### 2.1 三色限制（与 R6 保持严格一致，零深海军蓝、零第四色相）

| 令牌 | 暗夜（默认） | 日光高对比（`.jg-daylight`） | 用途 |
|---|---|---|---|
| `--jg-void` | `#000000` | `#FFFFFF` | 纯黑画布 / 纯白日光底 |
| `--jg-base` | `#0A0C10` | `#F4F6F8` | 表格行、索引条、遥测面板底 |
| `--jg-surface` | `#111419` | `#FFFFFF` | 抽屉面、表头、次级面板 |
| `--jg-accent` | `#00A6FF` | `#006BB3` | 唯一科技蓝主强调、激活轨、硬阴影 |
| `--jg-accent-hi` | `#38BDF8` | `#005596` | 电子计时超大数字、焦点高亮 |
| `--jg-text-hi` | `#FFFFFF` | `#000000` | 900 字重标题、正文 |
| `--jg-text-mid` | `#A3ADB8` | `#4B5563` | 辅助说明与标签 |
| `--jg-line` | `rgba(255,255,255,0.24)` | `rgba(0,0,0,0.22)` | 裸露表格与网格线 |
| `--jg-line-strong` | `#FFFFFF` | `#000000` | `4rpx`（2px）粗野实线外框 |

### 2.2 几何与质感铁律

- **绝对 0 圆角**：全站 `app.wxss` 及核心组件 `border-radius: 0`（无柔和圆角胶囊）。
- **可见 2px 粗边框**：主表格、卡片、抽屉顶框、筛选条统一 `4rpx solid var(--jg-line-strong)`。
- **硬偏移阴影**：重点卡片/翻面卡/主行动块采用 `6rpx 6rpx 0 var(--jg-accent)`，零模糊（blur=0）。
- **严禁 CSS**：零 CSS Grid、零 `backdrop-filter`、零 `filter: blur()`、零 `position: sticky`、零 WXSS `*`、零外部字体/CDN、零 `setData` 帧循环。

## 3. 四大布局模型（彻底告别纵向分区带）

### 3.1 横向分页 Deck（四角色工作台 + 签到页）

- **取消底部 5 项跳转坞**：全站 37 页零 `<jg-action-dock>` 残留。
- **顶部固定索引轨 `<jg-deck-rail>` + 渲染层 WXS 跟手游标 `.jg-deck-cursor`**：
  - 视口锁定 `height: 100vh`（`.jg-deck-page`），上方固定紧凑页头与横向索引轨，下方全屏 `<swiper class="jg-deck-swiper">` 承载独立 `<scroll-view scroll-y>`。
  - 滑动过程通过 `miniprogram/utils/motion.wxs` 的 `onDeckTransition` / `onDeckFinish` 在渲染层直接平移游标，**零 `setData` 通信**。
- **每页严格两层结构（`.jg-deck-layer` × 2）**，彻底消除一屏堆叠 5–6 个区块：
  - **学生端 (`pages/student/student`)**：`01 今日` / `02 成绩` / `03 出勤` / `04 通知`
  - **教练端 (`pages/coach/coach`)**：`01 今日` / `02 待办` / `03 计划` / `04 赛事`
  - **开发者端 (`pages/admin/admin`)**：`01 状态` / `02 审批` / `03 账号` / `04 训练组`
  - **家长端 (`pages/parent/parent`，严格只读)**：`01 概览` / `02 计划` / `03 成绩` / `04 考勤`（保留 BUG-F06 独立底栏退出入口）
  - **签到页 (`pages/student-attendance/student-attendance`)**：`01 今日签到` / `02 请假管理` / `03 历史考勤`

### 3.2 双栏连续粗野表格 + 底部详情/审批抽屉

- 榜单、待办、注册审核、账号、训练组、考勤名单、请假、赛事意向、成绩审核等列表页全面改用 **`.jg-tbl` + `.jg-tbl-row`**：
  - 左侧窄栏 `.jg-tbl-gutter`（`116rpx` 宽、`4rpx` 右分隔线）：放名次 `#1`、状态、日期或核心成绩读数。
  - 右侧 `.jg-tbl-body` + `.jg-tbl-end`：放主体信息、电光蓝超大读数与快捷按钮。
- 点击列表行展开 **底部抽屉 `.jg-drawer-sheet`**（支持 WXS `onDrawerStart/Move/End` 向下滑关闭），完成查看详情、筛选或审批；审批完成后触发行高亮闪烁 `.jg-row-flash`。

### 3.3 全屏图表舞台 + 底部筛选抽屉

- `student-statistics`、`student-report`、`stats-workbench`、`performance-leaderboard`、`attendance-statistics` 均将顶部多行筛选器收敛为单行 **`.jg-filter-bar`**（右侧 `筛选 ▾` 打开底部筛选抽屉），**首屏即直出全屏图表舞台 `.jg-chart-stage` 或双栏计时榜**。

### 3.4 三步横向分页表单（`coach-plan-edit`）

- 教练训练计划编辑器由冗长单页表单改为 `<jg-deck-rail>` + 3 步 `<swiper>` 横向表单（`01 基础信息` / `02 训练内容` / `03 核对发布`），底部固定 `.jg-step-foot`（`← 上一步` / `下一步 →`），第 3 步集中呈现发布前核对双栏表与 `保存草稿` / `发布计划` 操作。
