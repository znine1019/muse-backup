# V1.6 亲子关联与授权机制

**日期**：2026-10-14　**状态**：本地代码已完成 ｜ 云端待迁移 ｜ 真实账号待验收

## 1. 流程

1. 家长完成注册并由开发者审核通过（获得 `parent` 角色）。
2. **学生**在小程序内生成一次性关联凭证（`parent.create_invite`）。
3. **家长**使用凭证申请关联（`parent.redeem_invite`）。
4. **学生**确认或拒绝（`parent.student_decision`）。
5. **developer** 核验监护关系（`parent.review_link`，建议先线下核验）。
6. 核验通过 → 关联 `active` → 家长获得限定范围只读权限。
7. 任何一方或 developer 可解除（`parent.revoke_link`）。

## 2. 凭证安全

- 随机生成：10 位字符，字母表 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`（去除 0/O/1/I 等易混淆字符）。
- 数据库**只保存 SHA-256 哈希**（带固定 pepper），明文仅在生成响应中返回一次。
- 短时有效：30 分钟（`LIMITS.parentInviteTtlMinutes`）。
- 一次性：使用后置为 `used`；同一学生生成新凭证时，旧的未使用凭证立即置为 `expired`。
- 失败次数限制：单张凭证 `maxAttempts=5`；并对家长账号做窗口限流（15 分钟内失败 ≥ 10 次直接拒绝 `INVITE_REQUESTS_LIMITED`）。
- 禁止枚举：凭证与姓名/学号无关，不能直接输入 studentId 查看学生。

## 3. 状态机

| 类型 | 状态 |
|---|---|
| 凭证（kind=invite） | `open` → `used` / `expired` / `locked` |
| 关联（kind=relation） | `pending_student` → `pending_review` → `active`；`pending_student` → `rejected`；任意 → `revoked` |

并发：关联关系使用确定性文档 ID `deterministicId('parent_link', parentUserId, studentUserId)`（一对家长+学生仅一条记录）；状态更新使用事务 + 事务内状态复查（`LINK_NOT_PENDING`）。

## 4. 一对多与多对一

- 一个家长可关联多个学生（上限 `parentMaxLinkedStudents = 10`，超出返回 `LINK_LIMIT_REACHED`）。
- 一个学生可被多个合法家长关联。
- 学生可查看当前关联关系（`parent.list_my_links.asStudent`），家长可查看自己的申请状态（`asParent`）。
- 未成年学生需监护关系核验；成年学生需本人明确授权（学生确认环节即为其明确授权）；**不要求上传身份证件**，优先线下核验 + 线上审批，不采集无关敏感证件。

## 5. 失效与撤销

- 解除关联 / 账号停用 / 角色撤销 / 学生账号非 active → 下次读取立即被拒（每次读取重校验）。
- 撤销写入 `revokedBy` / `revokedAt` / `revokeReason` 并写审计日志。
