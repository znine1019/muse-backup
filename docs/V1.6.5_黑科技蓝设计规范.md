## 2. 为什么这套架构适合「体育训练管理 · 四角色 · 高频审批 · 户外使用」

1. **彻底打破旧版「圆角卡片堆砌」**：旧版把所有区块都套在 `24rpx` 圆角深蓝盒子里，导致每页首屏塞满边框与内边距、高频待办行被按钮挤扁。新版采用 **去卡片化通栏分区带（Architectural Band）+ 锐利直角/微切角（`0rpx` / `4rpx` / `8rpx`）**：视觉重心直接落在数字、状态点与动作上，一眼即可区分是全新一代系统。
2. **田径计时牌（Track Timing Board）语言**：田径训练天然以秒、米、出勤率、排名为核心。纯黑 `#000000` 画布配 `#38BDF8` 巨幅等宽计时数字与 `#00A6FF` 细线进度轨道，自带专业竞技计时系统气质，同时在 OLED 手机上省电且无深蓝浑浊感。
3. **户外强光双模式零妥协**：操场直射光下点击页头「日光」按钮，全页切换至 `#FFFFFF` 纯白画布 + `#000000` 纯黑正文（21:1 极高反差）+ 加深科技蓝 `#006BB3`（5.74:1），完全避免室外看不清。
4. **严格三色、零第四色相**：彩色（`#00A6FF` / `#38BDF8`）只出现在当前选中项、主操作强调、进度与数值高光、图表线条、状态点；错误与危险态使用**高反差黑白反相警示带 + `4rpx` 纯白实线左轨 + 明确文字前缀（异常/危险）**，连错误红都收敛入黑白结构，实现绝对纯净的黑、白、科技蓝三色体系。

## 5. 动效语言与小程序平台替代方案

- **唯一缓动曲线**：`cubic-bezier(0.16, 1, 0.3, 1)`，四档时长 `90 / 140 / 220 / 320ms`（招牌 `480ms`）。
- **核心动效清单**：
  1. 页面前进/后退方向转场（`.jg-enter-fwd` / `.jg-enter-back`，`320ms`、`±24rpx`）
  2. 区块/列表错峰（`.jg-stagger-0..5`，`40ms` 步进、`16rpx` 位移）
  3. 关键数字滚动（`.jg-num-roll`，`600ms` 等宽无抖动，零 `setData` 逐帧）
  4. 骨架扫光 `1.1s` → 内容 `180ms` 上移淡入（`.jg-skel-shimmer` + `.jg-content-in`）
  5. 表单聚焦纯描边 `140ms`（`#00A6FF`）+ 校验错误单次抖动 `140ms`（`.jg-shake`）
  6. 按钮 `90ms` 按压形变 + 亮度变化（CSS + `motion.wxs` 渲染层手势）
  7. 提交进度环 `.jg-spin-ring` → `360ms` `.jg-check-pop` 环形确认 + `480ms` `.jg-pulse-wrap` 雷达脉冲
  8. 角色/学生切换 `.jg-reveal`（`220ms`）+ 排行筛选 `.jg-scan`（`480ms` 电光蓝扫描线）
  9. PB 卡 `480ms` 3D Y 轴翻面（`<jg-flip-card>`，含 `@supports` + `SDKVersion < 2.16` 双分支 `220ms` 2D 交叉淡入降级）
  10. 原生 Canvas 2D 趋势图 `320ms` 折线生长 + `100ms` 延迟数值淡入（DPR 严格锁 `<= 2`，`detached()` 销毁）
  11. 顶部 `4rpx` 电光蓝细线刷新条（`.jg-ptr-line`）与活体状态点（`.jg-dot-live`）
- **小程序平台替代方案**：
  - `display: grid` / `gap` → 全面替换为 `display: flex; flex-wrap: wrap` + 负/右 `margin`（同步修复 `admin.wxss` 的 `.jg-filter-grid`）。
  - `backdrop-filter` / `filter: blur()` / `position: sticky` / GSAP / Google Fonts → 替换为 OLED 纯黑三阶灰度（`#000000/#0A0C10/#111419`）+ 发丝线 + `motion.wxs` 渲染层手势 + 系统原生字体 + `wx.pageScrollTo`。
  - WXSS 禁止通配符 `*` → `@media (prefers-reduced-motion: reduce)` 内显式列举全部动效类，并由全站 WXSS 静态扫描单测强制守门。
