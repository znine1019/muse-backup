# 微信云开发环境配置清单｜阶段0

本清单用于记录阶段1开始前必须由项目负责人完成或确认的事项。文中只填写配置状态和公开环境标识，**不要记录 AppSecret、API Key、私钥或云函数密钥**。

## 1. 必须人工确认

| 配置项 | 当前状态 | 人工操作 | 完成标准 |
|---|---|---|---|
| 小程序 AppID | 工程已配置，归属待确认 | 在微信公众平台核对该 AppID 是否属于乔格体育小程序主体 | 开发者工具导入时不提示 AppID 无效 |
| 微信开发者工具 | 当前执行环境未检测到 | 在 Windows 安装并登录开发者工具 | 能导入本目录并正常编译 |
| 云开发测试环境 | 未确认 | 在开发者工具中确认“微信云开发”是否可开通 | 能看到云开发控制台和测试环境 |
| 云环境 ID | 未配置 | 开通后记录在本地受控配置中 | 阶段1使用该环境初始化 `wx.cloud` |
| 数据库权限 | 未配置 | 阶段1创建集合前确认默认权限 | 客户端不能绕过云函数任意写业务数据 |
| 定位权限 | 未核实 | 在公众平台和真机检查 `wx.getLocation` 能力及隐私要求 | 记录“可用／不可用／替代流程待定” |
| 订阅消息 | 未核实 | 检查模板能力和个人主体适用范围 | 未确认前不把微信通知作为唯一渠道 |
| 隐私保护指引 | 未核实 | 在公众平台填写实际采集目的、范围和使用场景 | 与实际功能一致，不提前声明未实现能力 |

## 2. 云开发配置边界

- 只使用微信开发者工具内的“微信云开发”，不要混用独立腾讯云 CloudBase + JS SDK 的认证流程。
- 阶段0不调用 `wx.cloud.init`；只有环境 ID 确认后才在阶段1接入。
- 前端不得保存 AppSecret、云函数环境变量或云端管理员密钥。
- 身份依据必须由云函数从可信上下文取得，不能信任前端提交的 `openid`、`role` 或 `studentId`。
- 正式业务集合不开放客户端任意读写，所有数据归属和角色判断在云函数完成。
- 云存储中的头像、证明材料和导出文件必须使用受控访问路径，不生成公开永久链接。

## 3. 阶段1建议的初始集合

以下仅为权限系统所需的最小集合草案，字段和索引在阶段1确认后创建：

| 集合 | 用途 |
|---|---|
| `users` | 微信身份映射、账号状态、角色授权状态 |
| `student_profiles` | 学生注册档案，首期只创建必要字段 |
| `coaches` | 教练员资料与启用状态 |
| `training_groups` | 训练组基础信息 |
| `group_memberships` | 学生、教练员与训练组的归属关系 |
| `audit_logs` | 关键授权、审核和状态变更记录 |

数据库集合名、字段和索引尚未锁定，进入阶段1时需形成可审查的数据库草图。

## 4. 建议环境命名

- 开发环境：`joger-dev`
- 体验环境：`joger-staging`
- 正式环境：`joger-prod`

以上只是命名建议，不代表已经创建。每个环境应使用独立数据库和云函数配置，禁止把测试数据带入正式环境。

## 5. 人工完成后需要反馈的信息

只反馈以下非密钥信息：

1. 微信开发者工具是否成功编译。
2. AppID 归属是否已确认（不要在聊天中粘贴 AppSecret）。
3. 云开发是否可开通，以及测试环境的环境名称或环境 ID。
4. `wx.getLocation` 在公众平台的申请／权限状态。
5. 隐私保护指引和服务类目的审核状态。
6. 开发者工具控制台中出现的完整错误文本（如有）。

## 6. 本地验证命令

```powershell
node scripts/validate-phase0.js
```

该命令只验证工程结构和明显配置问题，最终仍需在微信开发者工具中编译和点击页面。
