# 乔格体育 V1.6｜技术架构与阶段0任务

## 当前已确定

- 仅有微信小程序（学生／教练员／开发者三种身份）；不开发独立PC端。
- 个人主体微信小程序，正在认证、备案审核；不假定定位接口已获批。
- Windows＋微信开发者工具＋Codex（DeepSeek API仅用于辅助写代码）。
- 云端服务优先微信开发者工具的「微信云开发」`wx.cloud`。**不要将“独立腾讯云 CloudBase + JS SDK”的认证流程与微信云开发混用。**
- 无AI训练系统；训练计划完全人工制定。

## 技术方案建议

```text
微信小程序（原生 WXML / WXSS / JS）
    ├─ 学生端 UI
    ├─ 教练员端 UI
    └─ 开发者端 UI
             │
             ▼
微信云开发云函数（可信身份／权限控制／业务校验／导出）
    ├─ 微信登录身份读取
    ├─ 用户与训练组授权
    ├─ 训练计划、考勤、请假、成绩审核、竞赛报名审核与名单导出
    └─ .xlsx 生成及安全下载
             │
             ▼
云数据库／云存储（核心业务记录、附件、审计日志）
```

- 前端不直接向业务数据库进行宽权限读写；云函数承担数据访问和鉴权。
- 支持角色多选，但绝不能仅靠前端切换按钮决定权限。
- 训练计划／签到／请假／成绩审核等写操作设计幂等性和修改日志。
- Excel导出（含赛事报名名单）由云函数生成真正的`.xlsx`文件，返回受控临时下载入口；用户仅能导出获授权记录。
- 排行榜仅使用审核通过的成绩；月、季、年的时间窗口及考勤口径稍后定规则。
- 竞赛报名信息及附件按教练所管训练组授权；区分俱乐部审核通过与赛事主办方正式报名完成。

## 阶段0（现在执行）

1. 在微信公众平台查到已经注册的小程序 AppID，勿在公开仓库泄露AppSecret。
2. 安装并登录微信开发者工具，在 Windows 上创建／导入原生小程序项目。
3. 替换`project.config.json`里的示例AppID，先在微信开发者工具中预览现有演示框架。
4. 验证`wx.cloud`能否开通云开发测试环境，记录环境ID（无环境时不影响离线UI预览）。
5. 检查个人主体当前账户对地理位置能力的权限与隐私要求，仅记录结论，**不要抢先设计绕过权限的手段**。
6. 使用Git建立本地版本库，确认`.gitignore`能忽略密钥、环境文件及临时导出内容。
7. 提交阶段0结果：能打开的小程序、初步导航、系统运行记录及下一阶段任务清单。

## 阶段0完成条件

- 微信开发者工具可以正常编译项目并打开首页。
- 可从首页进入三个“界面预览”（仅原型），没有把预览按钮当成真正角色授权。
- 含本地README、需求基线、环境待办、Git忽略清单。
- 无真实个人资料、微信AppSecret、DeepSeek Key或云端管理员密钥被写入仓库。

## 进入阶段1前必须确定

- AppID是否已配置成功；云环境是否成功开通。
- 选择服务端身份获取方式，验证从可信服务端读取OpenID。
- 数据库集合与索引草图、内部账号审核流程。
- 采用CloudBase微信云开发还是其他服务的最终决定。
