## 4. 动效规范与降级策略

- **统一缓动曲线**：`cubic-bezier(0.22, 1, 0.36, 1)`
- **时长阶梯**：微交互 `120ms` / 常规切换 `200ms` / 页面转场与图表 `300–320ms` / 招牌动效 `520–600ms` / 骨架屏扫光 `1.2s` / 列表错峰 `36ms`（位移 `20rpx` ≤ `24rpx`）。
- **性能红线**：
  1. 仅操作 `transform` 与 `opacity`，严禁布局属性动画。
  2. 全站严禁 `setData` 逐帧动画循环（已同步清理试穿页 `ui-preview` 旧计数循环）。
  3. 连续手势（左滑待办、抽屉下滑）由 `miniprogram/utils/motion.wxs` 在渲染层直接 `setStyle`。
  4. 所有页面级 UI 定时器在 `onHide` 与 `onUnload` 完整清理。
- **降级策略**：
  1. `@media (prefers-reduced-motion: reduce)`：将全部动画与过渡时长压降至 `0.01ms`，保留完整状态可见性。
  2. `@supports not (transform-style: preserve-3d)` + 基础库 `< 2.16` 自动检测：3D 翻面降级为 `200ms` 2D 交叉淡入。
  3. Canvas 2D 不可用或单测 Mock 环境：自动跳过帧动画直接完成静态重绘。
