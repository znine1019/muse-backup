# 乔格训迹系统｜V1.6.5「蓝黑白 · 高级感」前端设计规范

**版本**：V1.6.5（基于 `ui-ux-pro-max` 设计智能重塑，覆盖全部 37 个已注册页面）  
**设计语言**：`Minimalism & Swiss Style`（极简瑞士网格精工）× 三色系（蓝、黑、白）  
**基线原则**：仅改前端视觉、组件与动效；不改 `cloudfunctions/`、接口、数据库、集合、权限与环境变量；不引入外部库、外部字体、外部图片与原生 `tabBar`。

---

## 1. 设计智能依据（`ui-ux-pro-max` 检索结论）

通过全局安装的 `ui-ux-pro-max`（仓库 `11ca2b3`）执行 `search.py` 多域推理（`--design-system --density 7 --motion 4 --variance 3`、`--domain style`、`--domain ux`、`--domain chart`），提炼并本地化以下核心决策：
- **视觉体系**：`minimalism-and-swiss-style` —— 高反差、清晰层级、克制留白、单一强调色、避免装饰阴影与多余渐变。
- **可访问性底线**：文本对比度 ≥ `4.5:1`（WCAG AA）、触控目标 ≥ `88rpx`（44pt/48dp）、清晰焦点状态、`prefers-reduced-motion: reduce` 完整静态退化。
- **数据可视化**：单一目标 KPI 使用环形仪表（数字与口径文本并列展示，不依赖单一颜色传达含义）；时间序列趋势使用原生 Canvas 折线图（直标数值 + 清晰坐标轴 + 单一强调蓝）。

### 2.3 色彩使用禁区
1. **严禁引入第四色相**：禁止任何橙色、琥珀色、紫色、金色、青绿色或暖灰。
2. **严禁装饰性线性渐变与厚重投影**：唯一允许的渐变是主数据卡（`.jg-data-card` 与 `jg-flip-card` 正面）上的一层极淡径向光：`radial-gradient(circle at 88% 12%, rgba(143, 182, 255, 0.08) 0%, rgba(143, 182, 255, 0) 64%)`（透明度严格 `<= 8%`）。
3. **禁止旧色值残留**：彻底清除历史 F1（`#103A6B/#00A7C4/#F2711C/#EDF1F6` 等）及旧 R4 色值（`#05070A/#0B1219/#101A24/#132D49/#2F6FBF/#7FB2FF/#1E2C3A/#B9C6D4/#FF6B6B`）。

## 3. 排版、8 的倍数栅格、圆角与层级

### 3.1 字号与行高层级
- **页面主标题（`.jg-h1` / `.head-title`）**：`42rpx` / `font-weight: 700` / `line-height: 1.24` / `letter-spacing: -0.5rpx`
- **区块标题（`.jg-h2` / `.jg-sect-t`）**：`32rpx` / `font-weight: 700` / `line-height: 1.3`
- **卡片标题（`.jg-h3` / `.jg-card-t`）**：`28rpx` / `font-weight: 700` / `line-height: 1.35`
- **正文（`.jg-body`）**：`27rpx` / `line-height: 1.56`（兼容阶段7校验下限 `27rpx` ≈ 14px）
- **次级正文（`.jg-body-s`）**：`24rpx` / `line-height: 1.5`
- **辅助元数据（`.jg-sub` / `.jg-cap`）**：`24rpx` / `22rpx`
- **竞技大数值（`.jg-data-num`）**：`66rpx` / `font-weight: 700` / `line-height: 1`；全站数字统一双声明 `font-variant-numeric: tabular-nums` + `font-feature-settings: 'tnum'`。

### 3.2 间距栅格（8 的倍数体系）
- 统一采用 **8rpx 基准步进**：`8 / 16 / 24 / 32 / 40 / 48rpx`（容器页边距 `24rpx 32rpx`、卡片内边距 `32rpx`、区块间距 `32rpx`、相邻元素间距 `16rpx / 24rpx`）。
- 全站最小触控目标：`--jg-touch: 88rpx`（44px），按钮、可点标签、分段项、列表行、操作坞项均严格 `>= 88rpx`。

### 3.3 圆角、发丝描边与明度层级
- **三层明度代替投影**：画布 `#04060A` → 承托 `#0A0E14` → 卡片 `#0F141C` → 品牌聚焦 `#16304F`；每层以 `2rpx solid rgba(255, 255, 255, 0.08)` 发丝描边界定边缘，暗夜模式 **零投影**，日光模式仅保留克制轮廓 `0 2rpx 8rpx rgba(10, 14, 20, 0.04)`。
- **圆角梯度**：小胶囊/分段项 `16rpx`、按钮/输入框 `16rpx`、标准卡片/列表/主数据卡 `24rpx`、顶部抽屉 `32rpx 32rpx 0 0`、全圆徽标/环 `999rpx / 50%`。

## 4. 组件体系规范

### 4.1 按钮体系（5 变体 × 4 交互态，最小高度 `88rpx`）
- **主按钮（`.jg-btn` / `.jg-btn-accent`）**：暗夜纯白实底 `#FFFFFF` + `#04060A` 字；日光 `#16304F` 底 + `#FFFFFF` 字。
- **次按钮（`.jg-btn-secondary`）**：品牌深蓝 `#16304F` 底 + `#FFFFFF` 字 + `rgba(143,182,255,0.24)` 细描边。
- **幽灵按钮（`.jg-btn-ghost`）**：`#0A0E14` 承托底 + `rgba(255,255,255,0.08)` 发丝描边 + `#FFFFFF` 字。
- **危险按钮（`.jg-btn-danger`）**：`#0A0E14` 承托底 + `#FF5A5F` 描边与文字。
- **图标按钮（`.jg-btn-icon`）**：`88rpx × 88rpx` 正方形触控区，用于轻操作与工具栏。
- **交互状态**：
  - 按下态（`:active`）：`90ms` 形变 `scale(0.985)` + 亮度变化 `opacity: 0.88`；
  - 加载态（`.jg-btn-loading`）：内置 `.jg-spin-ring` 进度环；
  - 禁用态（`.jg-btn-disabled`）：`opacity: 0.42` + 发丝描边；
  - 成功态（`.jg-btn-success`）：`#2E6BFF` 实底 + `360ms` `.jg-check-pop` 环形勾选确认。

### 4.2 卡片、表单、胶囊、分段、列表、骨架与抽屉
- **卡片**：实底卡 `.jg-card`（`#0F141C`）、描边卡 `.jg-card-outline`（`#0A0E14`）、主数据卡 `.jg-data-card`（`#16304F` + ≤8% 径向微光）、翻面卡 `<jg-flip-card>`。
- **表单**：`.jg-input` / `.jg-textarea` / `.jg-picker` 默认发丝描边；聚焦 `.jg-input-focus` 采用 `140ms` 纯描边渐入 `#2E6BFF`（**无外发光**）；错误态 `.jg-input-error` 配合 `.jg-shake` 单次 `140ms` 抖动 + `.jg-field-err` 行内提示文案。
- **标签与状态胶囊**：`.jg-chip` / `.jg-chip-brand` / `.jg-chip-ok` / `.jg-chip-warn` / `.jg-chip-danger` / `.jg-chip-accent` / `.jg-badge`。
- **分段控件与标签页**：`.jg-seg` / `.jg-seg-item` / `.jg-seg-item-active`；`.jg-tabs` / `.jg-tab` / `.jg-tab-active`。
- **骨架屏与空态**：`.jg-skeleton` / `.jg-skel-shimmer`（`1.1s` 扫光）→ 加载完成后 `.jg-content-in`（`180ms` 上移 `16rpx` 淡入）；`<jg-empty>` 自包含空态组件。
- **轻提示、抽屉与操作坞**：`.jg-toast`、`.jg-drawer-mask` + `.jg-drawer-sheet`（低回弹打开 + WXS 下滑关闭）、`<jg-stat-ring>`、`<jg-action-dock>`（单排 5 项，行高 `88rpx`、总高 ≤ `112rpx`）。

## 5. 动效令牌与精确交互规范

| 令牌 / 机制 | 参数 | 说明 |
|---|---|---|
| 统一缓动曲线 | `cubic-bezier(0.16, 1, 0.3, 1)` | 极简精工无过冲曲线，禁用弹性回弹 |
| 四档标准时长 | `90ms` / `140ms` / `220ms` / `320ms` | 按压 / 微状态聚焦 / 常规切换与抽屉 / 页面转场与图表 |
| 招牌动效时长 | `480ms` | 3D 翻面、光栅扫描、签到光环扩散 |
| 列表错峰入场 | `40ms` × 步进，位移 `16rpx`（≤ `20rpx`） | `.jg-stagger-0..5`（`0..200ms`） |
| 关键数字滚动 | `600ms`（`.jg-num-roll`） | 等宽不跳动，纯 CSS/WXS/`this.animate()`，严禁 `setData` 逐帧 |
| 骨架扫光与内容揭示 | 骨架 `1.1s` → 内容 `180ms` | `.jg-skel-shimmer` + `.jg-content-in` |
| 成功环形确认 | `360ms`（`.jg-check-pop`） | 提交中 `.jg-spin-ring` → 成功后环形确认 |
| Canvas 趋势图 | `320ms` 折线生长 + `100ms` 延迟标签淡入 | DPR 严格 `Math.min(..., 2)`，`detached()` 销毁动画帧 |
| 下拉刷新指示器 | `.jg-ptr-line` 细线扫过 | 克制无圆环旋转噪音 |
| 渲染层手势 | `miniprogram/utils/motion.wxs` | 左滑待办、抽屉跟手下滑、90ms 按压反馈，零 `setData` 逐帧 |
| 降级红线 | `@supports not (transform-style: preserve-3d)` + SDK `< 2.16` + `@media (prefers-reduced-motion: reduce)` | 3D 翻面双分支降级 `220ms` 2D 交叉淡入；减弱动效用显式类列表静默退化（无 `*` 通配符） |

## 6. Skill 建议但小程序不可用项与平台替代方案

| `ui-ux-pro-max` 原始建议 | 微信小程序限制 | 本规范替代方案 |
|---|---|---|
| Glassmorphism / `backdrop-filter` / `filter: blur()` | 真机 WebView 渲染不一致且易掉帧，任务红线禁止 | 三层明度黑（`#04060A → #0A0E14 → #0F141C`）+ `rgba(255,255,255,0.08)` 发丝描边 + 主卡 `<= 8%` 径向微光 |
| `display: grid` + `gap` | 旧版 iOS 微信 WebView 兼容不稳定，任务红线禁止 | `display: flex; flex-wrap: wrap` + 8 的倍数 `margin` / `padding` |
| `position: sticky` / Scroll Parallax | 小程序原生滚动与吸顶易抖动，任务红线禁止 | `wx.pageScrollTo` 页内锚点跳转 + 固定底栏 `<jg-action-dock>`（`env(safe-area-inset-bottom)`） |
| GSAP 动画库 / SVG 图标库 / Google Fonts CDN | 严禁外部库、外部字体与 CDN | 原生 WXSS `transform/opacity` + `utils/motion.wxs` 渲染层手势 + `this.animate()` + 原生 Canvas 2D + 几何字标图标 |
| `@media (prefers-reduced-motion: reduce) { * { ... } }` | 微信 WXSS 编译器直接报 `unexpected token '*'` | 显式列举全部动效类名，静态压降 `animation-duration / transition-duration: 0.01ms !important` |
