## 2. 全局视觉规范实施结果

**导航栏与窗口**（`app.json`）：`navigationBarBackgroundColor` `#10263C` → **`#103A6B`**；`navigationBarTextStyle` 保持 `white`；`backgroundColor` `#F4F7FA` → **`#F2F5F9`**。

> 已核查：34 个页面**均无页面级 `navigationBarBackgroundColor` / `backgroundColor` / `navigationStyle` 覆盖**（页面 `json` 只设置 `navigationBarTitleText`、`enablePullDownRefresh`、`usingComponents`），因此改 `app.json` 即全站统一，且未改动任何页面注册、分包或 API 配置。

**颜色令牌**（`app.wxss`）：本轮批准的核心色全部落地。

| 语义 | HEX |
|---|---|
| 品牌深蓝 | `#103A6B` |
| 辅助深蓝 | `#17509E` |
| 竞技青 | `#00A7C4` |
| 能量橙 | `#F2711C` |
| **浅色底橙色文字** | **`#B54A07`**（本轮新增，替换原 `#D95F0E`） |
| 页面背景 | `#F2F5F9` |
| 主要文字 | `#0E1A28` |
| 成功 | `#0F7B5A` |
| 待处理 | `#B45309` |
| 危险 | `#C0392B` |

`#D95F0E` 已从 `app.wxss` 与 `jg-page-head.wxss` **完全移除**（`rg` 校验无残留），橙色文字统一走 `--jg-accent-2-strong: #B54A07`。

**对比度实测与修复**（WCAG 相对亮度）

| 文字 / 底色 | 对比度 | 结论 |
|---|---|---|
| `#B54A07` / `#FDEDE2` | 4.66:1 | PASS |
| `#B54A07` / `#FFFFFF` | 5.32:1 | PASS |
| 旧值 `#D95F0E` / `#FFFFFF` | 3.75:1 | 不达 AA，故本轮替换 |
| `#0E1A28` / `#FFFFFF` | 17.54:1 | PASS |
| `#64748B` / `#FFFFFF` | 4.76:1 | PASS（正文下限） |
| `#0F7B5A` / `#E8F6F0` | 4.72:1 | PASS |
| `#B45309` / `#FEF6E7` | 4.67:1 | PASS |
| `#C0392B` / `#FDEDEB` | 4.79:1 | PASS |
| 白字 / `#103A6B` | 11.42:1 | PASS |
| **旧强调按钮** 白字 / `#F2711C` | **2.94:1** | **不达 AA → 本轮修复** |
| **新强调按钮** `#08203F` / `#F2711C` | **5.55:1** | PASS |
| `#9FC0E4` / `#0F3563`（数据卡） | 6.51:1 | PASS |
| `#EAF3FF` / `#0F3563`（数据卡） | 10.97:1 | PASS |

**修复说明**：`.jg-btn-accent`（“去签到”按钮）原为 **白色文字 + #F2711C 填色 = 2.94:1**，既低于 AA 4.5:1、也略低于大字号 3:1。本轮**保留人工批准的能量橙 `#F2711C` 作为填色**，仅把文字改为品牌深海军蓝 `#08203F`，得到 **5.55:1**，同时与其他实底按钮（白字）区分出“强调”层级。若审核更倾向白字，备选方案是把填色加深到 `#B54A07`（白字 5.32:1）——两种方案均在报告中标出供选择。

**兼容性备援**
- 数字等宽：新增分组规则给 `.jg-num/.jg-data-num/.jg-data-col-v/.jg-kpi-v/.jg-ds-v/.jg-row-v` 补 `font-feature-settings: 'tnum'`，与既有 `font-variant-numeric: tabular-nums` 双声明。
- `.jg-refbar` 移除 `gap: 16rpx`，改用 `.jg-refbar-t { margin-right: 16rpx }`；`jg-` 段落现已无任何 `gap`。
- 新增 `.jg-clamp-2`（`-webkit-box` + `-webkit-line-clamp`）用于多行截断。

**触控目标 ≥88rpx**
- `.jg-jump-chip` 由 56rpx 提升到 **88rpx**（家长页内跳转）。
- 新增 `.jg-chip-tap`（`inline-flex` + `min-height: 88rpx`），用于**可点击**标签；已应用在教练待办筛选与全部功能角色切换，纯展示标签仍用 `.jg-chip`。

**新增工具类**（替代内联样式）：`.jg-skel-96/112/120/132/160`、`.jg-data-num-sm`、`.jg-chip-tap`、`.jg-clamp-2`、`.jg-tiles-3`。

**未做**：本轮**未删除任何 `jg-` 死代码**（按批准要求）。`jg-todo-p3` 与 `jg-chip-*` 变体为动态拼接，已保留。
