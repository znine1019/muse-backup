## 四、四角色首页布局建议

统一骨架（自上而下）：

```
① 页面头 jg-page-head（标题 + 元信息 + 角色徽标）
② 刷新条 jg-refbar（仅已有数据时出现）
③ 首要信息区（每角色不同，见下）
④ 待办 / 数据区
⑤ 常用功能
⑥ 全部功能入口（唯一、固定位置）
⑦ 说明 / 安全边界（jg-note）
```

**共同规则**：一屏只允许 1 张深蓝数据卡；"全部功能"入口固定在"常用功能"之后、退出之前，四个角色位置一致；不新增任何业务入口。

### 学生首页（`student`）

| 顺序 | 区块 | 组件 | 改造要点 |
|---|---|---|---|
| 1 | 今日训练 | `.jg-card` ×N + `.jg-btn-block` | 保留；主行动按钮按能否签到切换 `jg-btn-accent`（可签到）/`jg-btn-ghost` |
| 2 | 个人 PB | `.jg-data-card` | 保持唯一深蓝卡；缺数据显示文字而非 `-` |
| 3 | 出勤与目标 | `.jg-kpi-row` | 保持两列 |
| 4 | 近期进步 | `.jg-list` | 保留 |
| 5 | 俱乐部通知 | `.jg-list` | 保留 |
| 6 | 常用功能 | `.jg-tiles` + `.jg-list` | 瓦片由 6 个收敛到 **4 个**（计划/报告/成绩/考勤），其余并入"全部功能"，减少首页长度 |
| 7 | 全部功能 | `.jg-row` | 位置固定 |

| 1 | 关联学生选择 | `.jg-card` + `picker`，保持不变 |

| 顺序 | 区块 | 要点 |
|---|---|---|
| 1 | 系统运行状态 | `.jg-data-card`；内联 `font-size:52rpx` 改为专用类或 `.jg-data-col-v` |

| 4 | 训练组与教练范围 | 同上，补齐区块标题 |
| 5 | 全局管理入口 | 保留 10 项；"全部功能"置于最前 |
| 6 | 审计与安全边界 | `.jg-note`，保持 |

### 全部功能分类页（`all-features`）

- 结构保持不变：角色切换 chip → 身份说明 → 分类区块（`jg-sect-h` + `jg-tiles`）→ 返回工作台 → 权限说明。

- 家长端 `?section=` 深链接与 `feature-catalog` 配置**零改动**。

### 角色选择页（`role-select`）

- 由遗留改为 `jg-page`：`jg-page-head`（标题"选择身份"）+ `.jg-note`（说明）+ 角色按钮列表（每个角色一张 `.jg-card` 或 `.jg-btn-block`）。
- 保留"只显示服务端已授权角色"的语义文案；`.js` 的 `loadRoles`/`selectRole` **零改动**。
