# 黎曼猜想：能完整走完的推导，以及最后一步为什么不存在

说明：黎曼猜想本身没有证明，这份文件不假装有。下面是围绕它**已经被严密证明**的全部主要结论，一步不跳地写出来；最后单独说明：从这些结论到猜想本身，缺的那一步是什么、为什么补不上。

---

## 0. 起点定义

对复数 s = σ + it，当 σ > 1 时定义

ζ(s) = Σ_{n=1}^∞ n^(−s) = 1 + 2^(−s) + 3^(−s) + …

因为 |n^(−s)| = n^(−σ)，σ > 1 时级数绝对收敛，ζ 在半平面 σ > 1 内解析。

目标问题：把 ζ 延拓到更大的区域后，它的零点都在哪里。

---

## 1. 欧拉乘积（1737）

**结论**：σ > 1 时

ζ(s) = ∏_{p 素数} (1 − p^(−s))^(−1)

**证明**：
对每个素数 p，|p^(−s)| < 1，等比级数给出

(1 − p^(−s))^(−1) = 1 + p^(−s) + p^(−2s) + p^(−3s) + …

取有限个素数 p ≤ x，把这些等比级数相乘并展开：每一项形如 (p₁^a₁ ··· p_k^a_k)^(−s)。由算术基本定理（整数素因数分解唯一），乘积恰好等于

Σ_{n：n 的素因子全部 ≤ x} n^(−s)

当 x → ∞，右端与 ζ(s) 的差被 Σ_{n>x} n^(−σ) 控制，趋于 0。两边取极限即得欧拉乘积。∎

**推论 1**：ζ(s) 在 σ > 1 内没有零点。
因为 ∏_p (1 − p^(−s)) = Σ_n μ(n) n^(−s)（μ 是默比乌斯函数，|μ| ≤ 1，级数在 σ > 1 绝对收敛），
而 ∏_p (1 − p^(−s)) · ∏_p (1 − p^(−s))^(−1) = 1，
即 (Σ μ(n) n^(−s)) · ζ(s) = 1。两个因子都有限，所以 ζ(s) ≠ 0。∎

这一步的意义：素数（乘法结构）和 ζ 的零点（分析结构）被绑在了一起。这是整个理论的入口。

---

## 2. 解析延拓：先到 σ > 0

定义交错级数（狄利克雷 η 函数）

η(s) = Σ_{n=1}^∞ (−1)^(n−1) n^(−s)

它在 σ > 0 就（条件）收敛。把 ζ 的级数按奇偶拆开：

η(s) = ζ(s) − 2 · Σ_{n} (2n)^(−s) = ζ(s) − 2^(1−s) ζ(s) = (1 − 2^(1−s)) ζ(s)

于是 σ > 0、s ≠ 1 时

ζ(s) = η(s) / (1 − 2^(1−s))

这就把 ζ 延拓到了 σ > 0（除 s = 1）。在 s = 1：η(1) = ln 2 ≠ 0，而分母 1 − 2^(1−s) 在 s = 1 处为 0，所以 s = 1 是 ζ 的一个极点（留数为 1，可由 (s−1)ζ(s) → 1 验证）。∎

---

## 3. 延拓到全平面与函数方程（黎曼 1859）

用积分表示：对 σ > 1，

Γ(s) ζ(s) = ∫_0^∞ t^(s−1) / (e^t − 1) dt

（由 Γ(s) = ∫ t^(s−1) e^(−nt) dt 对 n 求和得到。）把积分改写成围道（Hankel 围道）积分后，右端对一切 s ≠ 1 有定义，给出 ζ 到 ℂ \ {1} 的全延拓，s = 1 是唯一极点、留数 1。

**函数方程**：定义

ξ(s) = π^(−s/2) Γ(s/2) ζ(s)

则 ξ(s) = ξ(1 − s)。

**证明骨架**（关键步骤齐全）：由 Γ(s/2) 的积分表示得

ξ(s) = ∫_0^∞ ψ(t) t^(s/2 − 1) dt，其中 ψ(t) = Σ_{n=1}^∞ e^(−π n² t)

雅可比恒等式（泊松求和的推论）：ψ(t) = (1/(2√t)) (1 + 2ψ(1/t)) − 1/2 的等价形式给出 ψ 在 t ↔ 1/t 下的变换律。把积分在 t = 1 处拆开，对 t < 1 的部分作代换 t → 1/t 并用变换律，整理后整个表达式在 s ↔ 1 − s 下不变，即 ξ(s) = ξ(1−s)。∎

---

## 4. 平凡零点与临界带

由函数方程：s = −2, −4, −6, … 时，Γ(s/2) 有极点，而 ξ 在左半平面没有其他来源的零点补偿，迫使 ζ(−2n) = 0。这些叫**平凡零点**。

其余零点（非平凡零点）由第 1 节（σ > 1 无零点）和函数方程（σ < 0 除平凡零点外无零点）夹住，只能落在

0 ≤ σ ≤ 1（临界带）

内，且关于临界线 σ = 1/2 和实轴对称分布：ρ 是零点，则 1 − ρ、ρ̄、1 − ρ̄ 都是零点。

**黎曼猜想**：非平凡零点全部满足 σ = 1/2。
注意对称性意味着：只要有一个零点偏离临界线，它就成对（实际是四个一组）出现。猜想等价于"一个都不许偏"。

---

## 5. 边界上也没有零点：ζ(1 + it) ≠ 0（t ≠ 0）

这是通向素数定理的关键一步，证明完整、初等。

对 σ > 1，由欧拉乘积取对数求导或直接展开：

ln ζ(s) = Σ_p Σ_{m=1}^∞ 1/(m p^(ms))

取实部（s = σ + iτ）：

Re ln ζ(σ + iτ) = Σ_p Σ_m cos(mτ ln p) / (m p^(mσ)) ≥ 某下界的控制量

关键不等式（对一切实数 θ）：

3 + 4cos θ + cos 2θ = 2(1 + cos θ)² ≥ 0

把它用到 τ = 0、t、2t 三处相加：

3 Re ln ζ(σ) + 4 Re ln ζ(σ + it) + Re ln ζ(σ + 2it) ≥ 0

即

ζ(σ)³ · |ζ(σ + it)|⁴ · |ζ(σ + 2it)| ≥ 1 ………… (*)

现在假设 ζ(1 + it) = 0（t ≠ 0），看 σ → 1⁺ 时 (*) 的三块：
- ζ(σ) ~ 1/(σ−1)，所以 ζ(σ)³ ~ (σ−1)^(−3)；
- ζ 在 1 + it 处解析且取值为 0，所以 |ζ(σ + it)| = O(σ−1)，四次方是 O((σ−1)⁴)；
- ζ(σ + 2it) 在 σ → 1 时趋于有限值 ζ(1 + 2it)（t ≠ 0 时 1 + 2it 不是极点），有界。

三块相乘 ~ (σ−1)^(−3) · (σ−1)⁴ · O(1) = O(σ−1) → 0，与 (*) 要求 ≥ 1 矛盾。
所以 ζ(1 + it) ≠ 0。由函数方程对称性，ζ(it)（t ≠ 0）在 σ = 0 上也没有零点。∎

**推论（素数定理，1896）**：ζ 在 σ ≥ 1 无零点 + 解析性，经陶伯型定理（或纽曼解析定理的围道论证）给出
π(x) ~ x / ln x。
黎曼猜想若成立，给出的误差项是 π(x) = Li(x) + O(√x ln x)，这是这个方法能达到的最优量级；反过来这个误差估计也等价于猜想。也就是说：**猜想 ⇔ 素数计数误差被压到平方根量级**，一步不多、一步不少。

## 6. 临界线上确实有无穷多个零点（Hardy, 1914）

定义 Hardy 函数 Z(t)：在临界线上取

ζ(1/2 + it) = e^(−iθ(t)) Z(t)

其中 θ(t) 是实的（由函数方程构造），于是 Z(t) 是实值函数，且 |Z(t)| = |ζ(1/2 + it)|。Z(t) 的实零点恰好对应临界线上的 ζ 零点。

Hardy 的论证结构：
1. ∫_0^T Z(t) dt 增长很慢（可由 ζ 的近似函数方程估计出远小于 T 的量级）；
2. 但 ∫_0^T |Z(t)| dt ≥ c·T^{某正幂级} 量级的大（由均值估计 ∫_0^T |ζ(1/2+it)|² dt ~ T ln T 推出下界）；
3. 若 Z(t) 只在有限个点变号（即临界线上只有有限个零点），则当 T 大于最后一个变号点后 Z 不变号，|∫Z| = ∫|Z|，与 1、2 的量级矛盾。

故临界线上有无穷多个零点。∎（第 1、2 步的均值估计是技术核心，此处给出的是完整逻辑链，各估计本身在解析数论教材中有逐行证明。）

后续推进（均为强事实）：Selberg 证明临界线上的零点占正比例；Conrey 证明至少 40%；数值计算已验证前 10^13 量级的零点全部在临界线上。但"正比例"和"全部"之间没有桥梁。

---

## 7. 最后一步：缺的是什么

把上面拼起来，人类现在确切知道的是：

- 零点只在临界带内（第 4 节）；
- 两条边界 σ = 0、σ = 1 上没有零点（第 5 节）；
- 中线 σ = 1/2 上有无穷多个、且占正比例（第 6 节）；
- 零点关于中线对称（第 4 节）。

猜想要求的是：带内**不存在**任何 σ ≠ 1/2 的零点。现有全部工具——欧拉乘积、函数方程、均值估计、数值验证——只能给出"分布意义上"的控制（多少个、大致在哪），**没有任何已知方法能排除"个别零点偏离中线"的可能性**。对称性只说偏离会成对出现，不说不能偏离。

历史上宣称的证明都倒在同一类地方：把"平均/比例/数值"层面的结论，偷换成"逐个排除"的结论。所以诚实的终点就是第 6 节：能完整走完的到此为止，再往前一步，目前不存在。
