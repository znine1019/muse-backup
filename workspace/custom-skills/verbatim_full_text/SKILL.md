# Extract a document verbatim in full

## Count the source before you read

- Count the pages, sections, annexes, and attachments in the source before you read any of it, and write those counts down as the checklist for completeness.

- Name the source file or link and the page range you will cover, and treat an annex or attachment as a separate item that must be read or listed as unread.

- If the source is a signing page or a viewer with no download entry, say so at the start and plan to read it page by page in that viewer.

## Read every part at full size

- Read the source at full zoom page by page, and do not skip a page, a table, a footnote, a stamp, or a signature page.

- Read image based pages visually rather than trusting extracted text alone, and re-read any page where the text is small, blurred, or cut off.

- Tick each page and annex off the checklist as you read it, and stop only when every item is ticked or listed as unread.

## Recheck money figures and names

- Recheck every money figure, rate, percentage, date, party name, and contract number against the source a second time before you write the delivery.

- Quote a penalty, commission, deposit, or fee from the exact clause where it appears, and name that clause beside the figure.

- If a figure the user asks about is not in the contract, say plainly that it is not in the contract and name where it must be obtained instead of guessing it.

## Disclose gaps before you send

- List every sentence, page, annex, or attachment you could not read in full, with its clause or page number, before you send the full text.

- Never call a delivery complete while any checklist item is unread, and never let the user be the one to discover a missing part.

- Count the sections and pages of the finished file before you send it, and report the count with the delivery.

## Alternatives for better results

- When the source offers a downloadable original, use that original instead of a viewer transcription.

- When the user only needs one clause or figure, deliver that clause with its source location instead of a full transcription.

- When the text is long and the user needs it in parts, deliver it in counted parts and keep the same checklist across every part.
