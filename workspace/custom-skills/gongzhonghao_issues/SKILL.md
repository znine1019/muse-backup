# Write Gongzhonghao issues

## Draft and deliver the article text

- Use this skill for every Gongzhonghao issue, including the scheduled run, and load it before you draft, convert images, or produce a video.

- Write the article in the user's plain, direct style and keep it factual and specific to the topic.

- Deliver the article body as plain dialogue text and never put it in a code block.

- Count the sections of any file you deliver before you send it and check that nothing was cut off.

- Tell the user plainly about any image or layout defect you could not fix instead of claiming the delivery is perfect.

## Prepare the cover and illustrations

- Convert the cover and every illustration to JPG before you deliver them.

- Do not deliver webp images because the editor reports a format error for them.

- Check each image after conversion and confirm the text and lines sit where they should.

- If an image still has a visible defect after remakes, name the defect when you deliver it.

## Produce the companion video when one is asked for

- Keep the video about one minute long.

- Write the narration script first and read that script aloud in the video.

- Do not use the video tool own narration.

- Keep the frames free of text unless the user asks for text in them.

## Available connectors

- Use `muse.connector_search` to find other connectors and `muse.skill_search` to find related skills.

- If nothing here fits, look on the web for a maintained API or MCP server and set it up with [Custom Connectors and MCPs](/opt/muse/skills/custom-connector-setup/SKILL.md), or build a custom connector.

## Alternatives for better results

- When the user does not answer a topic choice before the scheduled time, proceed with a new original topic and say that you did so.

- When an image keeps failing after two remakes, stop remaking it, disclose the defect, and ask the user whether to keep it or drop it.

- When the user asks for a verbatim official notice, re-typeset the notice text exactly and replace any missing image with a text heading rather than inventing content.
