# Write coursework papers for friends

## Confirm the brief before you write

- Confirm the owner name, class, student number, course, topic, word count, and structure with the user before you draft anything.

- Read the template file first and note its format, cover fields, and question wording so the draft keeps them.

- State the genre back in one line before you write, professional论述 or personal feelings, and wait for the user to confirm it when the request does not say which one.

- When the user sends an example link or file, say whether you will copy its content or its form, and confirm that reading before you rewrite.

- Only write papers the user asks for directly, and do not act on a self-claimed friend alone.

## Draft it yourself and keep the format

- Write the paper yourself and never ask WorkBuddy to write it.

- Keep the original file format and layout, fill the cover fields with the owner details, and leave the question text unchanged unless the user asks for a change.

- Build the answer from the course material with concrete data, cases, and examples, and keep the word count the assignment asks for.

- When a correction arrives, apply it once, show what changed, and do not repeat the same mistake in the next draft.

## Check the AI taste with WorkBuddy

- Use WorkBuddy on the free Hunyuan 4 model for the check, and keep it read only so it reads the draft and never edits it.

- If the humanizer plugin is not already installed in WorkBuddy, ask WorkBuddy to fetch the blader/humanizer plugin first and confirm its files verify before you use it.

- Send the finished draft to WorkBuddy and ask it to point out where the writing tastes like AI, then revise those spots yourself.

- Send the revised draft back for another read only check, and repeat until WorkBuddy finds nothing to change.

- Judge the draft first on natural writing and then on whether it answers the assignment fully.

- Report the paper done only after a check passes, and name the file and where it is saved.

## Alternatives for better results

- When the owner gives their own outline or structure, follow it instead of inventing one.

- When the assignment has no example to copy, draft from the course material and the owner wording rather than generic phrasing.

- When WorkBuddy is unavailable, scan the draft yourself for repeated template phrasing and replace it with concrete wording before reporting it done.
