冲拳 · 出拳与收拳CHONG QUAN

肘角 ≥ 142° 伸直收回 ≤ 115° 计数系统同标准判定
  1. 起势：双拳收于腰际 / 胸前，肘贴身，别把手垂着。
  2. 出拳：拳走直线快速打出，肘完全伸直（≥142°），拳眼向上。
  3. 收拳：沿原路收回胸前（肘角 ≤115°），伸 + 收完整一次才计数。
  4. 呼吸眼神：目视拳尖，出拳呼气、收拳吸气，肩膀别耸。
