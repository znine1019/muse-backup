# 乔格体育数字化训练管理系统｜V1.6 阶段0工程

这是乔格体育俱乐部内部使用的微信原生小程序工程。当前处于**阶段0静态原型**，用于验证项目结构、页面导航和微信开发者工具导入；不是可上线产品，也不具备真实身份权限。

## 当前状态

- 已完成：原生小程序目录初始化、首页及学生／教练员／开发者三端静态预览页面、页面路由检查。
- 已预留：`cloudfunctions/` 云函数目录，并在 `project.config.json` 中声明为云函数根目录。
- 尚未接入：微信登录、可信角色鉴权、云数据库、云存储、GPS 考勤、审批、Excel 导出、排行榜和竞赛报名业务。
- 强制边界：正式系统不接入 AI 训练 API；前端角色预览不代表真实授权；未审核成绩不能进入正式排行榜。

## Windows 本地验证

1. 安装并登录微信开发者工具，选择“小程序”并导入本目录。
2. 确认工具读取到 `project.config.json` 中的 AppID；该 AppID 必须属于本项目主体。
3. 在开发者工具中编译项目，确认首页可以打开。
4. 依次点击“学生端预览”“教练员端预览”“开发者端预览”，确认三个页面均能进入并能正常返回。
5. 如工具提示基础库或隐私配置问题，先记录提示原文，不要通过申请未验证权限来规避。

## 静态校验

项目不依赖第三方 npm 包。安装 Node.js 后可执行：

```powershell
node scripts/validate-phase0.js
```

该命令检查 JSON 配置、页面四件套、首页导航目标、云函数根目录、阶段0版本标识和常见密钥泄露模式。它不能替代微信开发者工具编译与真机验证。

## 安全提醒

不要把 AppSecret、云函数环境变量、DeepSeek Key、私钥或真实学生个人信息写入前端代码、日志或仓库。阶段0禁止上传任何真实学生数据，也禁止将演示工程作为正式版本发布。
